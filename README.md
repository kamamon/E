# IMMERSE FIT（イマースフィット）

**黒い画面の白い線のお手本をまねして動くと、本物の映像の「当たる瞬間」と自分の動きがぴったり重なる。**
海外で話題の「イマーシブ・インタラクティブ・ウォームアップ（没入型エクササイズ）」を、HTML と JavaScript だけで作ったアプリです。
GitHub Pages に置くだけで、スマホでもPCでも（プロジェクターの大画面でも）遊べます。

## 1種目の流れ（約1分・50回）

1. **紹介**：黒い画面に、白い線で描いたお手本が出て動きを見せます（例：片手で振り下ろす）。動いた腕や脚の跡が薄く残り、当たる瞬間に線がはじけます
2. **お手本といっしょに5回**：音声の「いち、に、さん…」に合わせて、まねして動きます
3. **場面スタート！**：お手本は右下の小さな丸へ。動きはそのままで、**実写の映像**に切りかわります。
   1つの場面で **4回（トントン×2）**。映像の中の「当たる瞬間」（ばちが太鼓に当たる・まきが割れる…）が音楽の拍に重なるように、映像の速さを少しずつ変えて合わせています
4. **5つの場面を2巡**：2巡目は同じ場面をもう一度。**片手の動きは反対の手**で（お手本も場面も左右が入れかわります）
5. **ラスト5回**：映像の上に 5・4・3・2・1 のカウントダウン、花火で「フィニッシュ！」

右下のお手本のまわりの **輪がいっぱいになった瞬間が、動くタイミング** です。設定で「場面の切りかえ」を2回ごとにすると、テンポよく次々に変わります。
はじめて開いたときは「遊び方」が出て、そのまま1分だけ試せます（ホームの「？遊び方」からいつでも見られます）。

## できること

- **4つのメニュー × 各500種目 = 2000種目**：全身／上半身／下半身／腕だけ
  - 種目 = 動き（67種類）× 5つの場面のセット。同じ動きでも、出てくる場面の組み合わせがちがいます
- **実写の場面**：2種類あります。**映像**（`clips/`：当たる瞬間がはっきり見える短い映像を、拍に合わせて速さを変えて再生）と、**写真**（`photos/`：同じ動きの写真を拍ごとに切りかえ、当たる場所へズーム・揺れ・閃光・擬音）。どちらも Wikimedia Commons で自由なライセンスのもとに公開されているもので、出典は `CREDITS.md` と設定画面にあります。同じ動きの素材が少ないときは、近い動きの素材も使います
- **イラストの場面（344種類）**：設定で「場面の映像」を「イラスト」にすると、アプリがその場で描くアニメーション（キッチン・工作・お祭り・スポーツ・冬・海・宇宙…）になります。実写の映像がない動きは自動でイラストになります
- **打点の効果音 500種類**：当たる瞬間に、拍ぴったりで鳴ります。和太鼓・金づち・まき割り・パンチ・水しぶき・ガラス・映画風のドーン…37の系統 × 大きさ・響き・硬さのちがい。録音ファイルは使わず、アプリがその場で合成します（容量ゼロ）。設定の「打点の効果音」で、**場面に合わせる**（場面に合う系統の中から種目ごとにちがう音）／**お気に入りから**（★をつけた音）／**1つに固定** を選べ、「効果音を試聴・えらぶ」で500種類を系統別に聴けます
- **自分の画像を当てはめる**：生成AIなどで作った画像を、動きごとの場面にできます（くわしくは下の「自分の画像を当てはめる」）
- **自動で作られる音楽**：お手本のあいだは静かめ → 場面が始まるとドロップ → 2巡目で盛り上がる
- **日本語の音声ガイド**：動きの名前、回数、「反対の手で！」「あと10回！」「ラスト！」
- **おまかせメニュー**：3〜20分。まだやっていない種目を優先し、同じ動きが続かないように選びます
- **今日のチャレンジ**、**種目の図鑑**（やった種目が「発見済み」に）、**記録**（連続日数・カレンダー・消費カロリーの目安）
- **テンポ**は5段階（ゆっくり 96 ／ ふつう 112 ／ はやい 128 ／ さらに速く 144 ／ 最速 160 BPM。1回 = 2拍）。プレイ中も「ひと休み」から変えられます。**静音モード**（ジャンプなし）
- **カメラで動きをチェック**（任意・GitHub Pages 版のみ）：場面に合わせて動けたかを数えて「シンクロ率」を出します。映像は端末の中だけで処理し、保存も送信もしません

## GitHub Pages で公開する

zip のままアップロードしても中身は展開されないので、**パソコンで解凍してから**中のファイルをアップロードします。
GitHub の画面からのアップロードは **1回に100ファイルまで** なので、`immerse-fit-github-upload.zip`（3つのフォルダに分けたもの）を使うと楽です。

1. GitHub で新しいリポジトリを作る（例：`immerse-fit`、Public）
2. zip を解凍し、`upload-1` フォルダを開いて **中身をすべて選び**、リポジトリの「Add file」→「Upload files」にドラッグ＆ドロップ →「Commit changes」
   （フォルダ `upload-1` そのものではなく中身を。`index.html` がリポジトリのいちばん上に来ていればOK）
3. 同じように `upload-2` の中身 → `upload-3` の中身 をアップロード（`clips` と `photos` は同じ名前のフォルダにまとまります）
4. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/(root)` にして「Save」
5. 1〜2分後に `https://ユーザー名.github.io/immerse-fit/` で開けます

自分の画像の zip（アプリの「書き出す」で作ったもの）も同じで、解凍してから `photos` フォルダをアップロードします。

### iPhone で全画面アプリにする

Safari で公開したページを開き、共有ボタン →「ホーム画面に追加」。ホーム画面のアイコンから開くと全画面で使え、オフラインでも起動します。
最初に画面をタップしたときに音が鳴るようになります（マナーモード中でも音楽が流れるように設定しています）。

## 実写の場面をふやす（自分で撮った動画）

1. 手元や足元を撮ります（例：にんじんをトントン切る、くぎを打つ。横向き・縦向きどちらでも。2〜8秒、当たる瞬間が3回以上）
2. `tools/clips.html` を開いて動画を選び、映像の中で**当たる瞬間**にしるしをつけます（H キー、←→ で1コマずつ）。「拍に合わせて試す」で、アプリと同じように拍に合わせて確認できます
3. 画面に出る1行を `js/clips.js` の `CLIPS` に追加し、動画を H.264 の MP4 にして `clips/` に置きます（画面に出る ffmpeg のコマンドが使えます）
4. 出典（作者・ライセンス）も同じ行に入ります。自分で撮った動画なら「自分で撮影」のままで構いません

同じ `act`（動きの種類）の種目に自動で使われます。`modes` は、その映像に合うお手本（片手 `one`・交互 `alt`・両手や全身 `both`）です。

## 自分の画像を当てはめる（生成AIの画像など）

ホームの「自分の画像を当てはめる」（または 設定 →「自分の画像」）から使います。

1. **動き**を選ぶ（振り下ろす・パンチ・キック…。種目は動きごとに場面を選びます）
2. **画像を入れる**：同じ場面の画像を2〜5枚（1組 8枚まで）。選ぶ・ドラッグ・貼り付け（ChatGPT などで画像をコピー → 貼り付け）のどれでも
3. **当たる場所をタップ**：画像ごとに。そこに光・揺れ・擬音が出て、画面ではその場所が真ん中に来るように置かれます
4. **効果音と擬音**：「おまかせ」なら場面の名前（例：鍛冶 → 金づちの音）から選びます。「変える」で500種類から選べます
5. **動かして試す** → **保存**

保存した組は、その動きの種目の場面に入ります（設定で「自分の画像を先に」／「自分の画像だけ」／「使わない」）。画像はこの端末のブラウザに保存されます（長い辺 1440px の JPEG に縮小）。

- **ファイル名でまとめて**：`hit-鍛冶-1.png`、`パンチ_サンドバッグ_2.jpg` のように「動き-場面名-番号」にして何枚も選ぶと、組をまとめて作れます。動きは英語（hit, punch, clap, push, pull, lift, stir, wipe, throw, kick, stomp, knee, jump, squat, step）でも日本語（振り下ろす・パンチ・キック…）でも
- **指示文の例**：画面の「画像を作るときの指示文の例」に、動きごとの例があります（コピーして ChatGPT などに貼れます）。当たる場所がはっきり見えて、人の顔や文字が入っていない画像が向いています

### サイトを開いた人みんなに出す（GitHub Pages）

1. 「自分の画像」の画面で **書き出す（zip）**
2. zip の中の `photos` フォルダを、リポジトリの `photos` フォルダに重ねてアップロード（`photos/custom.json` と `photos/custom/` が入ります）
3. コミットすると、サイトを開いた人の場面にも出ます。前に置いた `photos/custom/` があるときは、消してから置くと古い画像が残りません

別の端末やブラウザで続きを編集するときは、**読み込む（zip）** でその zip を選びます。サイトに置いた組は、編集すると自分の端末にコピーされます。

### 入っている写真の一覧に足す（開発向け）

`js/photos.js` の `PHOTOS` に1組を足し、写真（長辺 640px の JPEG）を `photos/` に置く方法もあります（出典を書く場合など）。

```js
{ id: 'hit-nail', act: 'hit', modes: ['one', 'alt'], name: 'くぎを打つ', short: 'くぎ', sfx: 'hammer', word: 'カン', quality: 4,
  images: [{ file: 'hit-nail-a.jpg', w: 640, h: 427, focus: [0.52, 0.48], credit: { file: '…', page: '…', author: '…', license: 'CC BY-SA 4.0', license_url: '…', changes: '縮小' } }, …] }
```

`images` は同じ動きの写真を2〜5枚（拍ごとに次の写真へ）。`focus` は当たる場所（写真の中の位置を 0〜1 で）。`sfx` は効果音（`hammer` などの名前か、`anvil-07` のような500種類のid）、`word` は当たった瞬間に出る擬音です。

## イラストの場面をふやす

`js/scenes/` の各ファイルは、場面の「テンプレート」の配列です。`vars`（バリエーション）1つが場面1つになります。

```js
{
  id: 'hit-cut', acts: ['hit'], modes: ['one'], theme: 'kitchen', sfx: 'chop',
  vars: [{ k: 'carrot', name: 'にんじんを切る', short: 'にんじん' }, ...],
  draw(g, s, v) { ... },     // 毎フレーム描く。s.p = 当たる位置からの離れぐあい（0 が当たる瞬間）、s.k = 何回当たったか
  hit(g, s, k, v) { ... },   // 当たった瞬間のエフェクト（k は 1 か 2）
}
```

- 新しい場面を足すと、同じ `acts`（動きの種類）の種目に自動で使われます
- `tools/scenes.html?file=hit` … 場面の一覧画像（当たる前・当たった直後・2回目のあと・縦長・横長）。`?play=hit-cut:carrot` で1つを音つきで再生
- `node tools/validate.mjs hit` … すべての場面を全モード・左右で動かしてエラーや名前の長さをチェック
- `tools/motions.html` … お手本の動きと「当たる瞬間」の確認

### 手元で動かす

ES モジュールを使っているため、`index.html` を直接ダブルクリックでは開けません。フォルダで次を実行して `http://localhost:8080` を開いてください。

```
python3 -m http.server 8080
```

`npm install` → `npm run build` で、1ファイル版のプレビュー（`dist/preview.html`）を作れます。
